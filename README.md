# 🔢 Calculadora Mobile em React 

Um aplicativo de calculadora simples desenvolvido para dispositivos móveis usando React.

## Funcionalidades

- Operações básicas: adição, subtração, multiplicação e divisão
- Design responsivo para mobile
- Interface limpa e intuitiva

## Tecnologias Utilizadas

- React
- JavaScript
- CSS

## Como Executar

1. Clone o repositório:
    
    ```bash
    git clone https://github.com/torqu4to/calculator-mobile-react.git
    ```
    
2. Instale as dependências:
    
    ```bash
    npm install
    ```
    
3. Inicie o aplicativo:
    
    ```bash
    npm start
    ```
